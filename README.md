# Hotel Reservation & Management System

A full-stack hotel reservation and management system developed using React, Laravel, and MySQL.

## Features

- Online hotel reservations
- Admin dashboard
- Room management
- Booking management
- Guest management
- Authentication system
- Email notifications
- Responsive UI
- REST API integration

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3

### Backend
- Laravel
- PHP
- REST APIs

### Database
- MySQL

## Project Status

Completed and deployed for a real-world client project.
